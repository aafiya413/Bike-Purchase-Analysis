# Bike-Purchase-Analysis
This project analysis factors influencing bike purchase using Excel. 
It includes:
-Pivot Tables for data summarization.
-Interactive slicers for purchase filltering.
-charts for visualization of purchase trends.
-Dashboards for overall insights.
###Tools used
-Microsoft Excel
### Key Insights
-Income and commute distance have a significant impact on bike purchasing decisions.
-Males are more likely to buy bikes then females.
-Middele age people are contributing more in bike purchasing.
-Visualization helps in identifying customer segments more likely to buy bikes.
